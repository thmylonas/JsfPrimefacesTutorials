# JsfPrimefacesTutorials

A tutorial application on JSF, Primefaces, Hibernate/JPA, Maven (no archetype)

GitHub link:

* [JsfPrimefacesTutorials](https://github.com/thmylonas/JsfPrimefacesTutorials.git)

### Extra Notes - History

This was my first project started before 7 years, when I was first starting learning Server-side development. Initially,
it was called as "MySpringHibernateJsfWebApp" where I was using and Spring Framework. After 7 years I removed the Spring
Framework and leaving the project as a pure JSF, Primefaces project.
