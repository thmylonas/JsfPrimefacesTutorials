1. When we use a Primefaces CSS-Grid, we never make the rows with fixed height.
We make the content element fixed and we let the row to wrap the content.

2. All the <h:outputStylesheet> in the <h:head> of the mainTemplate.xhtml file.
Because the does not contain <ui:composition>, and in the other pages the contain <ui:composition>,
everything out of it, it will be ignored.

3. #{resource['images/java_frameworks/Java.jpg']

4. In pages, the <ui:define> will be in this order:
head-metadata, head-title
top_section, center_section, right_section, leftSection, bottom_section

5. [Better writing] In the css entry: ".ui-menuitem-icon.icon_name", can have whatever name it wants.
To solve the problem that the menuitem is not displayed, we have to change the dimensions of the
icon itself with image editors.

6. Add JSTL Library: xmlns:c="http://java.sun.com/jsp/jstl/core", or xmlns:c="http://xmlns.jcp.org/jsp/jstl/core",
and Maven[javax.servlet, jstl, 1.x]
