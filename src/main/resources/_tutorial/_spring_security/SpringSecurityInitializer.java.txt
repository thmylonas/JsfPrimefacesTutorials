package com.thomasmylonas.spring_mvc_jsf_pf_web_app._tutorial._spring_security;

import org.springframework.security.web.context.AbstractSecurityWebApplicationInitializer;

/**
 * Site: https://howtodoinjava.com/spring5/security/security-java-config-enablewebsecurity-example
 * <p>
 * Initialize spring security
 * In Spring, security is implemented using DelegatingFilterProxy.
 * To register it, with spring container in Java configuration, we shall use AbstractSecurityWebApplicationInitializer.
 * The Spring will detect the instance of this class during application startup, and register the DelegatingFilterProxy
 * to use the springSecurityFilterChain before any other registered Filter. It also registers a ContextLoaderListener.
 * <p>
 * This class automatically:
 * creates and configures the: "org.springframework.web.filter.DelegatingFilterProxy"
 * which delegates to the bean:
 * "FilterChainProxy springSecurityFilterChain" (where "FilterChainProxy implements javax.servlet.Filter")
 * <p>
 * The "springSecurityFilterChain", known as the Spring Security Filter Chain, chains together one or more additional filters
 * to provide different security features.
 * The "WebSecurity", which is created by WebSecurityConfiguration
 * 1. creates the "springSecurityFilterChain" and
 * 2. can be used to create other FilterChainProxy beans.
 * <p>
 * This code can be implemented with XML-config: "web.xml" - "org.springframework.web.filter.DelegatingFilterProxy"
 */
