H2-Database without "Java-Based_Control_Of_H2-Database"
-----------------------------------------------------------

Info:
The "Java-Based_Control_Of_H2-Database" is the Java code I copy everywhere, to control the "H2-Database"

Start the "H2_Server" and open the "H2 Console" (Way_1)
-----------------------------------------------------------

- In the pom-dependencies we add the dependency "com.h2database/h2", and
- We start the project
In this case:
- The "H2_Server/H2-Database" starts automatically
- The browser WebApp "H2 Console" opens automatically on the OS's default browser
- The application in "Visual_VM/JConsole" application, is called "org.h2.tools.Console"

Start the "H2_Server" and open the "H2 Console" (Way_2)
-----------------------------------------------------------

- We find in the classpath (External Libraries), the "h2-x.x.xxx.jar"
- We open the "h2-x.x.xxx.jar" in the "File_Explorer" and we Double-Click it
- We open the "h2-x.x.xxx.jar" in the Terminal, and we run the "".\h2-x.x.xxx.jar"
In this case:
- The "H2_Server/H2-Database" starts automatically
- The browser WebApp "H2 Console" opens automatically on the OS's default browser
- The application in "Visual_VM/JConsole" application, is called "org.h2.tools.Console"

Start the "H2_Server" through the IntelliJ_Database_Tools ("In-Disk-H2_Database")
-------------------------------------------------------------------------------------

This way applies ONLY:
- In case of "In-Disk-H2_Database"
- When the database "xxx.mv.db" and its schema is already created somehow and exists somewhere

Create a new Data Source with the next configuration:
- Name: "<DB_Name>"
- Connection type: "Embedded"
- Driver: "H2"
- Path: "~/xxx.mv.db"
- Authentication: "User & Password"
- User: sa
- Password:
- URL: "jdbc:h2:~/DB_Name;DB_CLOSE_DELAY=-1"

Notes:
- This way, demands to install the "H2_Driver". IntelliJ will install the latest version of the "H2_Driver"
- The application in "Visual_VM/JConsole" application, is called "com.intellij.database.remote.RemoteJdbcServer"

Attention:
If the database "xxx.mv.db" is created with an older version of the dependency "com.h2database/h2",
because IntelliJ installs teh latest version of "H2_Driver", this will lead to the error:
    DBMS: H2 (no ver.)
    Case sensitivity: plain=mixed, delimited=exact
    [90048][90048] Unsupported database file version or invalid file header in file "xxx.mv.db" [90048-232]
    The write format 2 is smaller than the supported format 3 [x.x.xxx/x].
The "xxx.mv.db" needs to be created with the lastest with the [x.x.xxx/x] version that the error reports.

Stop the "H2_Server"
------------------------

As the "H2-Database" is a Java-based application, the only way to stop the "H2_Server/H2-Database", are the next steps:
- Open the "Visual_VM/JConsole" app, and
- Apply "Kill Application" for the "org.h2.tools.Console"
- Apply "Kill Application" for the "com.intellij.database.remote.RemoteJdbcServer"
